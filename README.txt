공공구매 실시간 통합검색 + 3종 Excel 자동조회

실행
1. ZIP을 한 폴더에 압축 해제
2. start.bat 실행
3. http://127.0.0.1:5050 접속

같은 폴더에서 자동으로 찾는 Excel
1) 파일명에 '조달업체 등록 내역' 포함
2) 파일명에 '중소기업 확인업체 내역' 포함
3) 파일명에 '마포구 관내 희망기업 목록' 포함

파일명의 연월, 괄호, (1) 같은 추가 문자는 상관없습니다.
동일 종류가 여러 개면 수정일이 가장 최근인 파일을 사용합니다.
Excel 임시파일(~$...)은 제외합니다.

마포구 희망기업 파일 자동 인식 시트
- 생산시설 지정현황 → 중증장애인생산품
- 사회적기업
- 예비사회적기업
- 사회적협동조합

사업자등록번호가 있는 경우 조달업체/중소기업/희망기업 자료를 같은 업체로 결합합니다.
검색 결과에는 기업유형, 업체명, 업종·품목, 전화, 주소, 사업자번호, 출처가 함께 표시됩니다.

온라인 실시간 조회
나라장터, 꿈드래, 우리몰, 에이블마켓, 사회적기업진흥원, 서울계약마당
사이트의 차단/개편 시 해당 출처만 실패로 표시되고 Excel 및 다른 성공 출처 결과는 계속 표시됩니다.

추가기능: 마포구 계약횟수 자동조회
- 업체검색 결과의 업체명을 서울계약마당 '계약업체명'으로 재조회
- 발주기관: 마포구
- 계약일자: 해당연도 1월 1일 ~ 실행 당일
- 마포구 전체 계약건수 집계
- 가능한 경우 계약별 담당/발주부서를 확인하여 부서별 건수 집계
- 0건: '마포구 실적 0건'
- 구 전체 5건 이상: '구 전체 5회 도달'
- 동일 부서 2건 이상: '부서 2회 도달'
주의: 횟수 판정은 사용자가 제시한 내부 기준에 따른 보조 확인 기능이며 예외/계약유형 등 최종 적용기준은 별도 확인 필요.

추가 출처: 마포구 관내업체 등록 목록, 마포구 나라장터 등록업체 현황
공식 공개 목록을 읽고 로컬에서 키워드 필터링합니다. 게시판의 페이지 이동이 JavaScript 전용인 경우 첫 페이지까지만 수집될 수 있으며, 최대 12페이지 제한을 적용합니다. 검색결과는 전체 목록의 완전성을 보장하지 않습니다.

마포구 관내 여부: 소재지에 마포구가 있으면 관내, 타 시도 주소는 관외, 정보 부족 시 확인 필요. 계약 실적 여부와 별개입니다.
