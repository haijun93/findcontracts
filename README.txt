공공구매 실시간 통합검색 + 3종 Excel 자동조회

실행
1. ZIP을 한 폴더에 압축 해제
2. start.bat 실행
3. http://127.0.0.1:5050 접속

같은 폴더에서 자동으로 찾는 Excel
1) 파일명에 '조달업체 등록 내역' 포함
2) 파일명에 '중소기업 확인업체 내역' 포함
3) 파일명에 '마포구 관내 희망기업 목록' 포함

파일명의 연월, 괄호, (1) 같은 추가 문자는 상관없습니다.
동일 종류가 여러 개면 수정일이 가장 최근인 파일을 사용합니다.
Excel 임시파일(~$...)은 제외합니다.

마포구 희망기업 파일 자동 인식 시트
- 생산시설 지정현황 → 중증장애인생산품
- 사회적기업
- 예비사회적기업
- 사회적협동조합

사업자등록번호가 있는 경우 조달업체/중소기업/희망기업 자료를 같은 업체로 결합합니다.
검색 결과에는 기업유형, 업체명, 업종·품목, 전화, 주소, 사업자번호, 출처가 함께 표시됩니다.

온라인 실시간 조회
나라장터, 꿈드래, 우리몰, 에이블마켓, 사회적기업진흥원, 서울계약마당
사이트의 차단/개편 시 해당 출처만 실패로 표시되고 Excel 및 다른 성공 출처 결과는 계속 표시됩니다.

추가기능: 마포구 계약횟수 자동조회
- 업체검색 결과의 업체명을 서울계약마당 '계약업체명'으로 재조회
- 발주기관: 마포구
- 계약일자: 해당연도 1월 1일 ~ 실행 당일
- 마포구 전체 계약건수 집계
- 가능한 경우 계약별 담당/발주부서를 확인하여 부서별 건수 집계
- 0건: '마포구 실적 0건'
- 구 전체 5건 이상: '구 전체 5회 도달'
- 동일 부서 2건 이상: '부서 2회 도달'
주의: 횟수 판정은 사용자가 제시한 내부 기준에 따른 보조 확인 기능이며 예외/계약유형 등 최종 적용기준은 별도 확인 필요.

추가 출처: 마포구 관내업체 등록 목록, 마포구 나라장터 등록업체 현황
공식 공개 목록을 읽고 로컬에서 키워드 필터링합니다. 게시판의 페이지 이동이 JavaScript 전용인 경우 첫 페이지까지만 수집될 수 있으며, 최대 12페이지 제한을 적용합니다. 검색결과는 전체 목록의 완전성을 보장하지 않습니다.

마포구 관내 여부: 소재지에 마포구가 있으면 관내, 타 시도 주소는 관외, 정보 부족 시 확인 필요. 계약 실적 여부와 별개입니다.

개선된 판정 및 검증
- 계약 결과 테이블, 업체명, 발주기관, 계약일자와 페이지별 수집 건수를 검증합니다.
- 업체명은 공백/대소문자 정규화 후 정확히 일치하는 계약만 집계합니다.
  동명이인 업체의 구분은 사업자번호를 공식 자료에서 별도 확인해야 합니다.
- 점검 페이지, 구조 변경, 누락된 계약은 0건이 아니라 조회실패로 표시합니다.
- 담당부서가 불명확하면 횟수기준 여유 대신 부서 확인 필요를 표시합니다.
- 게시판 출처만으로 주소를 만들지 않으며 주소 미상은 관내로 확정하지 않습니다.
- 지역을 선택하면 주소가 확인되는 업체만 표시합니다. 주소 미상 업체는 전국 검색으로 확인하세요.
- 새로운 검색은 이전 요청을 취소하며 늦게 도착한 응답은 적용하지 않습니다.

회귀 테스트 (프로젝트 폴더에서 실행)
python -m unittest discover -s tests -v
node tests/test_search_race.js
Node.js는 화면 회귀 테스트용이며 앱 실행에는 필요하지 않습니다.

404 재발 방지: launcher v2
최신 ZIP 전체를 새 폴더에 압축 해제하고 start.bat을 실행하세요.
실행 창에 Findcontracts launcher v2와 Application directory가 표시됩니다.
서버 시작 및 홈페이지 응답 검증 후에만 브라우저를 엽니다.
5050 포트가 사용 중이면 5051~5059 중 사용 가능한 포트를 선택합니다.
수동 접속 시 고정된 5050 주소 대신 실행 창의 Open 주소를 사용하세요.
기존 프로세스를 자동 종료하지 않으므로 이전 실행 창은 Ctrl+C로 종료하세요.
앱 파일이 누락되면 설치/실행을 중단하고 압축 해제를 안내합니다.
브라우저 없이 실행: python launch.py --no-browser

계약실적 연도 선택
검색 설정의 계약실적 연도에서 조회 연도를 선택합니다. 기본값은 올해입니다.
2026년: 2026-01-01부터 조회 당일(한국 날짜)까지.
2025년: 2025-01-01부터 2025-12-31까지.
2021년부터 올해까지 선택할 수 있으며 미래 연도는 조회하지 않습니다.
선택 연도는 계약실적에만 적용됩니다. 업체 Excel/희망기업 목록은 현재 자료입니다.
계약정보 API: /api/mapo-contracts?year=2025&company=업체명
연도 선택은 조회 조건을 설정합니다. 브라우저 생성 계약 목록의 자동 수집 제한은 그대로입니다.
